# Habit Tracker Dashboard

A fully customizable, industrial spreadsheet-style daily habit and schedule tracking web application built with React, Tailwind CSS, and Firebase.

## Features
- **Spreadsheet Interface:** Taupe/beige/grey industrial layout with daily and weekly progress indicators.
- **Centralized Settings:** Bulk edit habit names, emojis, target years, and active calendar months in one modal.
- **Dynamic Calendar Engine:** Auto-calculates days per month (including leap years) and weekday headers.
- **Real-Time Analytics:** Interactive doughnut charts, progress bars, and dual-line mental trend curves.
- **Data Synchronization:** Dual persistence across browser LocalStorage and Firebase Firestore.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn
